# 🎧 Mivi Website Clone

A front-end website recreation inspired by the Mivi website, built from scratch using **HTML, CSS, and JavaScript**.

This project focuses on recreating a modern consumer-electronics website experience with a strong visual layout, product-focused sections, navigation, promotional content, and responsive front-end design.

## 📖 About The Project

The **Mivi Website Clone** is a front-end development project created to practice and demonstrate modern website development using core web technologies.

The goal of this project was to recreate the visual experience of a modern audio-product website while developing the interface from scratch.

The website focuses on:

- Clean navigation
- Product-focused design
- Large visual hero sections
- Modern typography
- Image-based product presentation
- Structured content sections
- Interactive front-end elements
- Responsive website layout
- Organized HTML, CSS, and JavaScript structure

This project was developed as part of my front-end development and UI implementation practice.

---

# ✨ Features

## 🧭 Navigation

The website includes a structured navigation bar that provides access to different product and service categories.

Main navigation sections include:

- Earbuds
- Soundbars
- Earphones
- Speakers
- Support

The navigation is designed to remain simple and easy to understand while maintaining the visual style of the website.

---

## 🎬 Hero Section

The homepage contains a large visual hero section designed to immediately capture the user's attention.

The hero section includes:

- Large background visual
- Promotional headline
- Strong typography
- Product-oriented messaging
- Full-width visual presentation

Example:

> "Hear as clear as a fox"

The hero section establishes the visual identity of the website and creates an engaging first impression.

---

## 🎧 Product-Focused Design

The website is designed around audio products such as:

- Earbuds
- Earphones
- Soundbars
- Speakers

The layout emphasizes product imagery and promotional content to create a modern e-commerce-style experience.

---

## 🎨 Modern UI Design

The interface uses a modern visual approach with:

- Dark navigation
- High-contrast typography
- Large visual sections
- Product imagery
- Spacious layouts
- Strong visual hierarchy

The design focuses on making the products the main visual element.

---

## 📱 Responsive Layout

The website is designed with responsive layouts so that the interface can adapt to different screen sizes.

The project focuses on providing a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile devices

---

## ⚡ Interactive Elements

JavaScript is used to add front-end interaction and functionality to the website.

Depending on the section, JavaScript handles interactions such as:

- Navigation behavior
- UI interactions
- Dynamic elements
- User interactions
- Front-end functionality
